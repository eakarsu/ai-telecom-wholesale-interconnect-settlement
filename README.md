# Telecom Wholesale Interconnect Settlement

Reconcile wholesale voice traffic, routing, rates, quality credits, and bilateral carrier settlements.

**Primary buyer:** Telecom carriers and network operators. **Evidence:** interconnect agreements, CDRs, routes, prefixes, durations, rates, quality, disputes, invoices, and settlements.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Interconnect agreement library
- Carrier route registry
- CDR ingestion
- Prefix destination mapping
- Billable duration calculation
- Rate deck versioning
- Least-cost route validation
- Traffic imbalance analysis
- Quality SLA credit
- Fraud traffic exclusion
- Invoice generation
- Counterparty invoice audit
- Dispute workflow
- Net settlement reconciliation
- Route carrier analytics

Run `./start.sh`, then open <http://127.0.0.1:4723>. API: `5723`.

Administrator: `runtime-admin@example.com` / `LocalDemo!2026`. Operator and reviewer credential buttons are available on the login page.
